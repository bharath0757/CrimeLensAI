# Architecture Diagram

Place your system architecture diagram here.

## Recommended Tools
- [Excalidraw](https://excalidraw.com/) — collaborative, hand-drawn style
- [draw.io](https://app.diagrams.net/) — detailed technical diagrams
- [Figma](https://figma.com/) — polished presentation-ready diagrams

## Instructions
1. Create your diagram using one of the tools above
2. Export as `architecture.png` (PNG, at least 1200px wide)
3. Place the file in this directory: `docs/architecture-diagram/architecture.png`
4. The README.md will automatically display it

## What to Include
- All 5 service modules and their connections
- Database layer (PostgreSQL + Neo4j)
- Frontend app and its API calls
- Data flow arrows showing: Ingestion → Extraction → Graph → Ledger audit trail
- External integration points (future CCTNS/NATGRID)
